FleetProvider ทำหน้าที่อะไร?

ภาพรวมเส้นทางข้อมูล ตั้งแต่ Server ส่งข้อมูลรถเข้ามา จนถึงส่วนต่าง ๆ ของ Dashboard นำข้อมูลไปแสดงผล

คำตอบสั้น: ใช่บางส่วน — มันเป็นศูนย์กลางของ ข้อมูลและ state ที่เกี่ยวกับ Fleet ซึ่งหลาย component ใช้ร่วมกัน แต่ไม่ได้ดูแลทุกอย่างในระบบ และไม่ได้เป็นฐานข้อมูลหรือ Backend

ขอบเขตที่ควรจำ

FleetProvider จัดการ state ร่วมของหน้าฝั่ง Fleet ส่วน component ปลายทางยังรับผิดชอบการวาด UI ของตัวเอง และ Server ยังคงรับผิดชอบการดึงหรือบันทึกข้อมูลจริง หากภายหลังเชื่อม GPS จริง ส่วนจำลองใน advanceFleet() ก็ควรถูกแทนด้วยข้อมูลจาก API, WebSocket หรือ stream

Tree การไหลของข้อมูล

อ่านจากบนลงล่าง: Server ส่งข้อมูลตั้งต้นเข้า Provider จากนั้น Provider ดูแล state และกระจายผลลัพธ์ไปยังส่วนแสดงผล

ตัวจำลองข้อมูลสด

advanceFleet()

ถูกเรียกทุก 3 วินาทีเมื่อเปิด Live

Input

รถทั้งหมด, เวลาที่ผ่านไป และเวลาปัจจุบัน

Process

ตรวจความสดของข้อมูล สุ่มหลุด/ต่อสัญญาณ และขยับพิกัดรถที่กำลังวิ่งตามความเร็วกับทิศทาง

Output

อาร์เรย์รถชุดใหม่ โดย clone เฉพาะคันที่ต้องเปลี่ยน

ศูนย์กลางหลัก

FleetProvider()

ครอบ Dashboard ทั้งโซน

Input

snapshot จาก Server และ children ที่อยู่ภายใน

Process

สร้าง state, เปิด interval, กรอง เรียง หารถที่เลือก และสร้างชุด actions

Output

แจก StateContext และ ActionsContext ให้ component ลูกทั้งหมด

อ่านข้อมูล

useFleet()

ใช้ในส่วนที่ต้องแสดงข้อมูล

Input

ไม่รับ argument แต่ต้องถูกเรียกภายใต้ FleetProvider

Process

อ่านค่าปัจจุบันจาก StateContext และตรวจว่ามี Provider ครอบอยู่หรือไม่

Output

vehicles, view, sorted, selected, filter, sort, now และ live

สั่งเปลี่ยนข้อมูล

useFleetActions()

ใช้ในปุ่ม ช่องค้นหา และตัวกรอง

Input

ไม่รับ argument และต้องอยู่ภายใต้ FleetProvider

Process

อ่านเฉพาะ ActionsContext จึงไม่ต้องผูกกับข้อมูลรถที่เปลี่ยนทุก 3 วินาที

Output

คำสั่ง setStatus, setDataStatus, setScope, setSearch, setSort, select, resetFilter และ toggleLive

เลือกคันรถ

useSelectVehicle()

Hook แบบย่อที่เตรียมไว้

Input

ตอนเรียก hook ไม่รับค่า แต่ function ที่คืนมารับ ID รถหรือ null

Process

หยิบ select จาก actions แล้วครอบด้วย useCallback ให้ reference คงที่

Output

Function สำหรับเลือกหรือยกเลิกเลือกรถ ปัจจุบันยังไม่มีจุดเรียกใช้ในโปรเจกต์

Logic ภายใน FleetProvider

ส่วนเหล่านี้ไม่ใช่ function ที่ export แต่เป็นตัวทำงานสำคัญภายใน Provider

Live Effect

เมื่อ live = true จะตั้งเวลาเรียกทุก 3 วินาที อัปเดต now และส่งรถทั้งหมดเข้า advanceFleet() เมื่อปิด Live หรือออกจากหน้า จะล้าง interval

Visibility Effect

เมื่อผู้ใช้กลับมาที่แท็บ จะตั้ง lastTick ใหม่ เพื่อไม่เอาเวลาที่หายไปตอนซ่อนแท็บมาคำนวณจนรถกระโดดไกล

buildFleetView()

นำรถ + filter + เวลาปัจจุบันมาสร้างรายการรถที่ผ่านตัวกรอง พร้อมจำนวนรถแต่ละสถานะและสถานะความสดของข้อมูล

sortVehicles()

นำ view.vehicles มาเรียงตามเวลาอัปเดต ทะเบียน ความเร็ว หรือสถานะ โดยไม่แก้ array ต้นฉบับ

หา selected

ใช้ selectedId ค้นหาข้อมูลรถเต็มก้อนจาก vehicles ถ้าไม่ได้เลือกหรือหาไม่พบจะได้ null

Actions

แต่ละคำสั่งแก้ state เฉพาะส่วน เช่น setSearch() เปลี่ยนข้อความค้นหา, resetFilter() คืนตัวกรองเริ่มต้น และ toggleLive() สลับสถานะ Live
